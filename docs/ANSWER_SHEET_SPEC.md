# 答案卡格式說明（版型 v1）

唯一規格來源：`src/omr/layout.ts`。答案卡產生器（`src/sheet/svg.ts`）與辨識引擎都讀這個檔案，
所以「印出來的位置」與「辨識假設的位置」不可能不一致。單元測試會檢查圓圈不重疊、不碰定位點、在紙內。

座標單位 mm，原點在 A4（210 × 297 mm）左上角。

| 元素 | 規格 |
|---|---|
| 定位標記 | 4 個實心黑方塊，邊長 8 mm，中心 (12,12)、(198,12)、(198,285)、(12,285)；與紙邊距 8 mm |
| 標題 | 考試名稱、題數 |
| 手寫欄 | 姓名 (18,26) 92×14、座號 (114,26) 34×14、班級 (152,26) 40×14 — 只印框不辨識；姓名欄會裁成圖片存檔 |
| 座號劃記 | 十位列 y=55、個位列 y=63，數字 0–9，x = 46 + 7.5·d |
| 考試識別碼條 | y=74，22 格（4 mm 方格、間距 6 mm，起點 x=22）：恆黑起始格＋16 位元資料＋4 位元 CRC-4/ITU＋恆白結束格 |
| 答案區 | 5 欄 × 10 列，最多 50 題。欄起點 x = 14 + 37·c；題號右緣 +8；選項 A–D 中心 +13、+20、+27、+34；列 y = 92 + 10·r（第 6 列起再加 5 mm 分組間隔） |
| 圓圈 | 半徑 2.75 mm，0.3 mm 深灰外框，內部留白（選項字母印在欄頭） |

題數少於 50 時，只印出前 N 題；座標不變，所以同一個引擎可以處理 10–50 題。

## 列印

- A4 直向、邊界「無」、縮放 100%。等比例縮放（例如印表機「符合頁面」）可正常辨識。
- 四角黑塊必須完整印出，不要被裁切或被裝訂釘擋住。
- 影印可以，但避免淡印或底色過深；不要摺疊。

## 預印座號

答案卡頁面可勾選「預印座號 1–N」，系統會在每張的座號欄寫上數字並把座號劃記塗黑，學生就不用自己劃。

## 識別碼

每份考試建立時隨機產生 1–65535 的代碼。掃描時讀到的代碼若與目前選定的考試不同，會警告；
若對應到本機另一份考試，可一鍵改用該考試批改。CRC 可以偵測所有單一位元錯誤。

## 修改版型

改 `layout.ts` 任何數字都會同時影響列印與辨識，**舊版答案卡將無法正確辨識**。改完必須：

1. 把 `LAYOUT_VERSION` 加一（印在答案卡上）。
2. `npm test` 全部通過。
3. 重新列印答案卡，並重跑真實照片測試。
